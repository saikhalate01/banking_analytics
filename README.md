# Customer Banking Analysis
Banking Customer Analytics

📌 Project Overview

Banking Customer Analytics is a SQL and Power BI Business Intelligence project developed to analyze customer behavior, account activity, transactions, cards, loans, and branch performance.

The main objective is to help a bank understand its customers, identify valuable customer segments, analyze financial activity, and support better business decisions using data.

🎯 Objectives

- Understand customer demographics and customer segments
- Analyze account types and customer account usage
- Analyze card types and card usage
- Understand transaction behavior and spending patterns
- Analyze loan distribution and loan values
- Compare branch-level performance
- Identify useful business insights from customer and financial data

🛠️ Tools & Technologies

- SQL Server / SSMS – Data analysis and business queries
- Power BI – Interactive dashboards and data visualization
- DAX – Measures and KPI calculations
- Power Query – Data transformation
- GitHub – Project version control and documentation

🗂️ Database Tables

The project uses the following tables:

- Customers
- Accounts
- Branches
- Cards
- Loans
- Merchants
- Transactions

🔗 Data Model

The main relationships used in the project include:

- Customer → Accounts
- Customer → Loans
- Account → Cards
- Account → Transactions
- Branch → Accounts
- Merchant → Transactions

Transactions are connected to customers through the Account table.

Analyzes:

- Transaction amount

- Spending patterns

🏦 Loan Analysis

Analyzes:

- Total loan amount
- Number of loans
- Loan distribution
- Interest-related information
- Customer loan activity

🏢 Branch Analysis

Analyzes:

- Branch distribution
- Account distribution by branch
- Branch-level customer/account activity

- Total Loans

- Total Cards
- Average Account Balance
- Customers by Segment

- Products per Customer

💡 Business Insights

The analysis helps identify:

- Customer segments with higher value
- Popular account and card types
- Customer transaction behavior
- High-value loan activity
- Branch-level differences

- Opportunities for cross-selling banking products
