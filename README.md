🏦 Banking Customer Analytics

📌 Project Overview

Banking Customer Analytics is a Business Intelligence project developed using SQL Server and Power BI to analyze customer behavior, accounts, cards, transactions, merchants, loans, and branches.

The project transforms banking data into an interactive dashboard that helps understand customer patterns, financial activity, product usage, transaction behavior, loan performance, and branch activity.

---

❓ Problem Statement

Banks generate large amounts of customer and financial data, but raw data alone does not provide clear business insights.

The challenge is to analyze this data and identify customer segments, account and card usage, transaction trends, merchant activity, loan patterns, and branch performance in a simple and interactive way.

This project addresses the problem by using SQL for data analysis and Power BI for visualization and business intelligence.

---

🎯 Objectives

- Analyze customer demographics and segmentation
- Understand account and card usage
- Analyze transaction and merchant activity
- Evaluate loan performance and interest trends
- Analyze branch-level activity
- Monitor important banking KPIs
- Identify customer and financial patterns
- Support data-driven business decisions

---

🗃️ Dataset

The project uses a synthetic banking dataset containing information related to:

- Customers
- Accounts
- Cards
- Transactions
- Merchants
- Loans
- Branches

The data is connected through relevant customer, account, merchant, loan, and branch relationships to provide a complete view of banking activity.

---

🛠️ Tools & Technologies

- SQL Server – Data management and analysis
- Power BI – Dashboard development and visualization
- DAX – Measures and KPI calculations
- Power Query – Data transformation and preparation

---

📊 Dashboard Summary

The Power BI report contains five interconnected pages with navigation buttons for easy movement between different areas of analysis.

🏠 1. Overview

The Overview page provides a consolidated summary of the bank's customer base and overall financial activity.

It highlights major customer, account, transaction, loan, balance, and tax-related information, allowing users to quickly understand the overall business position before moving into detailed analysis.

---

👥 2. Customer Analysis

The Customer Analysis page focuses on understanding the bank's customers through their demographics, income groups, customer segments, product usage, gender, and account activity.

It also provides insights into active customers, dormant accounts, and customer balances, helping the bank understand customer behavior and identify opportunities for better engagement.

---

💳 3. Account & Card Analysis

The Account & Card Analysis page focuses on how customers use banking accounts and card products.

It provides an understanding of account distribution, account types, card types, and customer-segment-wise account usage. This helps identify product usage patterns and understand how different customer groups interact with banking products.

---

💰 4. Transaction & Merchant Analysis

The Transaction & Merchant Analysis page analyzes transaction activity across time, account types, customer segments, and merchants.

It helps identify transaction trends, spending activity, average transaction behavior, and merchant-level patterns, providing a clearer view of financial activity within the bank.

---

🏦 5. Loan & Branch Analysis

The Loan & Branch Analysis page focuses on the bank's loan portfolio and branch activity.

It provides insights into loan amounts, number of loans, average loan value, interest-rate trends, customer-segment-wise loan distribution, and branch activity across cities.

---

🔘 Dashboard Navigation

The report includes interactive navigation buttons:

Overview → Customer Analysis → Account & Card Analysis → Transaction & Merchant Analysis → Loan & Branch Analysis

This allows users to move easily between different analytical sections of the report.
